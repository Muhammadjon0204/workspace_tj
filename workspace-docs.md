

# 🧩 Что это за веб-система?


В данном проекте необходимо разработать **backend (REST API) для веб-сервиса управления коворкингом**.

Коворкинг — это пространство, где компании или отдельные люди могут **арендовать рабочие места, комнаты для встреч и другие рабочие зоны** на определённое время.

Представим, что существует сервис **WorkSpace.tj**.
Этот сервис помогает компаниям **бронировать рабочие места для своих сотрудников**.

Например, компания может забронировать:

* рабочий стол
* переговорную комнату
* конференц-зал

на **конкретную дату и время**.

---

## Как работает система

В системе есть несколько основных сущностей.

### 1. Компании (Companies)

Компании — это клиенты коворкинга.

Например:

* SoftClub
* Alif Tech
* DC Bank

Каждая компания может:

* зарегистрироваться в системе
* бронировать рабочие места
* просматривать свои бронирования

Администратор системы может:

* добавить компанию
* изменить данные компании
* удалить компанию

---

### 2. Комнаты (Rooms)

Коворкинг состоит из различных комнат.

Например:

* **Open Space** — общий рабочий зал
* **Meeting Room** — переговорная комната
* **Conference Room** — большой зал для встреч

У каждой комнаты есть:

* вместимость (сколько людей может находиться)
* цена за аренду в час

Например:

| Комната         | Вместимость | Цена |
| --------------- | ----------- | ---- |
| Open Space      | 20          | 10   |
| Meeting Room    | 8           | 20   |
| Conference Room | 40          | 50   |

---

### 3. Рабочие места (Workspaces)

Внутри каждой комнаты есть **рабочие места**.

Например:

Комната **Open Space** может содержать:

* Desk 1
* Desk 2
* Desk 3
* Desk 4

А комната **Meeting Room** может содержать:

* Table 1
* Table 2

Каждое рабочее место принадлежит определённой комнате.

---

### 4. Бронирования (Bookings)

Основная задача системы — **создание бронирований**.

Компания может забронировать рабочее место **на определённую дату и время**.

Например:

Компания **SoftClub** хочет забронировать:

* Desk 1
* дата: 10 марта 2026
* время: с 10:00 до 12:00

Система должна сохранить:

* какая компания сделала бронирование
* какое рабочее место
* дату
* время начала
* время окончания
* стоимость бронирования
* статус бронирования

Статусы могут быть, например:

* pending (ожидает подтверждения)
* confirmed (подтверждено)
* cancelled (отменено)

---

### 5. Стоимость бронирования

Система должна сохранять **стоимость бронирования**.

Например:

если цена комнаты **10 за час**, а бронирование **2 часа**:

```
2 × 10 = 20
```

Эта сумма сохраняется в поле:

```
total_price
```

---

### 6. Статистика

Система должна уметь возвращать **общую статистику**.

Например:

* сколько всего бронирований было создано
* какая общая сумма всех бронирований
* сколько компаний пользуется системой

Это поможет администратору понять:

* насколько активно используется коворкинг
* сколько денег приносит сервис

---

## Какой интерфейс будет использовать этот API

Этот REST API может использоваться:

* веб-сайтом
* мобильным приложением
* административной панелью

Например:

**Администратор** через веб-панель может:

* создавать комнаты
* добавлять рабочие места
* смотреть статистику

**Компании** через сайт могут:

* выбрать рабочее место
* выбрать дату и время
* создать бронирование

---

## Что должны реализовать студенты

Студенты должны разработать **backend API**, которое позволит:

* управлять компаниями
* управлять комнатами
* управлять рабочими местами
* создавать бронирования
* получать статистику

При этом необходимо использовать:

* ASP.NET Core Web API
* PostgreSQL
* Dapper
* Dependency Injection
* Logging (ILogger)

## 🇹🇯 Тоҷикӣ

Дар ин проект донишҷӯён бояд **backend (REST API) барои системаи идоракунии коворкинг** таҳия кунанд.

Коворкинг — ин ҷойест, ки ширкатҳо ё одамон метавонанд **ҷойҳои кориро барои як муддати муайян иҷора гиранд**.

Тасаввур кунед, ки як сервис бо номи **WorkSpace.tj** вуҷуд дорад.
Ин сервис ба ширкатҳо имкон медиҳад, ки **барои кормандони худ ҷойҳои кориро брон кунанд**.

Масалан, ширкат метавонад брон кунад:

* мизи корӣ
* утоқи мулоқот
* толори конференсия

барои **як сана ва вақти муайян**.

---

## Чӣ тавр система кор мекунад

Дар система якчанд объектҳои асосӣ мавҷуданд.

### 1. Ширкатҳо (Companies)

Ширкатҳо — мизоҷони коворкинг мебошанд.

Мисол:

* SoftClub
* Alif Tech
* DC Bank

Ҳар ширкат метавонад:

* дар система сабт шавад
* ҷойҳои кориро брон кунад
* бронҳои худро бинад

Администратор метавонад:

* ширкат илова кунад
* маълумоти ширкатро иваз кунад
* ширкатро ҳазф кунад

---

### 2. Утоқҳо (Rooms)

Коворкинг аз чанд утоқ иборат аст.

Мисол:

* **Open Space** — толори умумии кор
* **Meeting Room** — утоқи мулоқот
* **Conference Room** — толори калон

Ҳар утоқ дорад:

* иқтидор (чанд нафар ҷой мегирад)
* нархи як соат

---

### 3. Ҷойҳои корӣ (Workspaces)

Дар дохили ҳар утоқ **якчанд ҷойи корӣ** вуҷуд дорад.

Масалан:

Дар утоқи **Open Space**:

* Desk 1
* Desk 2
* Desk 3

Дар утоқи **Meeting Room**:

* Table 1
* Table 2

Ҳар ҷой ба як утоқ тааллуқ дорад.

---

### 4. Бронҳо (Bookings)

Қисми асосии система — **брон кардани ҷойҳои корӣ** мебошад.

Ширкат метавонад ҷойро барои **як сана ва вақти муайян** брон кунад.

Мисол:

Ширкати **SoftClub** мехоҳад брон кунад:

* Desk 1
* сана: 10 март 2026
* вақт: 10:00 – 12:00

Система бояд нигоҳ дорад:

* кадом ширкат брон кард
* кадом ҷой
* сана
* вақти оғоз
* вақти анҷом
* маблағ
* статуси брон

---

### 5. Маблағи брон

Система бояд маблағи бронро ҳисоб кунад.

Мисол:

агар нархи як соат **10** бошад ва брон **2 соат** бошад:

```
2 × 10 = 20
```

Ин маблағ дар майдони **total_price** нигоҳ дошта мешавад.

---

### 6. Статистика

Система бояд статистикаро баргардонад:

* шумораи умумии бронҳо
* маблағи умумии бронҳо
* шумораи ширкатҳо

Ин ба администратор имкон медиҳад фаҳмад:

* коворкинг чӣ қадар истифода мешавад
* сервис чӣ қадар даромад меорад
